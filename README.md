### 🌱 Plant Disease Prediction System
**Empowering Agriculture with AI**

</div>

**Tech Stack:** `Python` • `TensorFlow` • `Flask` • `MobileNetV2` • `HTML/CSS`

An intelligent web application that revolutionizes agricultural diagnostics by using deep learning to identify plant diseases from images. Helps farmers and agricultural professionals make informed decisions quickly and accurately.

**🎯 Key Features:**
- ✅ Implemented **MobileNetV2 transfer learning** for efficient disease classification
- ✅ Built responsive **Flask web interface** with real-time image processing
- ✅ Achieved **high prediction precision** through model optimization
- ✅ Comprehensive training visualization with detailed evaluation metrics
- ✅ Multi-class disease detection across various plant species

**[📂 Source Code](https://github.com/victoroki/plant_diseases_prediction)**
